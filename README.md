# Student Management System (C)

## Overview
A console-based application to manage student records with role-based access control.

## Features
- User authentication (admin/user roles)
- Add student records (admin)
- View all student records
- Search student by roll number
- Delete student records (admin)

## Technologies Used
- C Programming
- File Handling
- Role-Based Access Control (basic)

## Project Structure
- src/ → main source code
- data/ → stores student and user data

## How to Run
gcc src/main.c
./a.out
